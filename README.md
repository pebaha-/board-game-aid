# Board Game Aid

A React app with helpers for board games, including player management and
Secret Hitler role assignment.

## Development

Install dependencies and start the Vite development server:

```sh
pnpm install
pnpm dev
```

Vite prints the local development URL in the terminal.

## Verification

Run the test suite and create a production build:

```sh
pnpm test
pnpm build
```

The production output is written to `dist`.

## Deployment

Create the production files that are deployed to GitHub Pages:

```sh
pnpm build
```
